# Easy-Web AI 扩展 — 使用说明

> 分支：`feat/ai-chat-memory`  
> 主文档：[README.md](../../README.md)

## 快速开始

```bash
# 1. AI 模块测试（无需 API Key）
python -m pytest tests/ai/ -v

# 2. 测试 + 钉钉通知
python scripts/ai/run_module_tests.py

# 3. Chat 模式（Mock，生成登录用例）
python -m ai.chat --mock "帮我生成一个登录用例"

# 4. 交互式 Chat
python -m ai.chat --mock
```

## 配置

LLM 敏感信息通过项目根目录 **`.env`** 配置（不要写入 `settings.yaml`）：

```bash
copy .env.example .env
```

`.env` 常用变量：

| 变量 | 说明 |
|------|------|
| `LLM_API_KEY` | API Key（启用真实 LLM 时必填） |
| `LLM_BASE_URL` | 服务地址，默认 OpenAI 兼容 `/v1` |
| `LLM_MODEL` | 模型名称 |
| `LLM_ENABLED` | 是否启用（true/false） |
| `LLM_MOCK` | Mock 模式，不调真实 API |
| `DINGTALK_WEBHOOK` | 钉钉机器人 Webhook（可选） |

`settings.yaml` 中 `llm` 段提供非敏感默认值；`.env` 会覆盖同名字段。

启用真实 LLM：

```bash
# 编辑 .env
LLM_API_KEY=sk-xxx
LLM_ENABLED=true
LLM_MOCK=false
python -m ai.chat "帮我生成搜索用例"
```

## 目录约定

| 路径 | 用途 |
|------|------|
| `ai/` | AI 扩展层（微内核之上） |
| `data/ai/staging/` | 待确认用例（不直接写 data/） |
| `data/ai/knowledge.db` | 四层记忆库（gitignore） |
| `tests/ai/` | 模块测试 |
| `scripts/ai/` | 运行脚本 |
| `logs/ai/` | Tool 调用日志（gitignore） |

## 双模式说明

| 模式 | 入口 | 说明 |
|------|------|------|
| CI/CD | `python main.py` | 确定性执行，默认不启用 LLM |
| Chat | `python -m ai.chat` | 交互式辅助，用例写入 staging 待确认 |

## 四层记忆

| 层级 | 名称 | 存储位置 |
|------|------|----------|
| L1 | 工作记忆 | working_buffer 表 |
| L2 | 情景记忆 | episodes 表 |
| L3 | 语义记忆 | semantic_chunks + selector_registry |
