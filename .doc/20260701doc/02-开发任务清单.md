## T04 — SQLite Schema（详细）

**文件**：`ai/memory/store.py`

**表结构**：

```sql
-- L1 工作记忆（会话内）
working_buffer (session_id, role, content, tool_calls, created_at)

-- L2 情景记忆
episodes (id, session_id, summary, trajectory_json, success, created_at)

-- L3 语义记忆
semantic_chunks (id, source, content, metadata_json, weight, created_at)
selector_registry (id, url_pattern, element_role, selector, by_type,
                   success_count, fail_count, stale, updated_at)

-- L4 程序记忆元数据
skill_candidates (id, pattern_name, description, success_count,
                  confidence, promoted, created_at)

-- 会话
sessions (id, title, created_at, updated_at)
```

**验收**：`MemoryStore.init_db()` 幂等；路径默认 `data/ai/knowledge.db`。

## T05 — MemoryManager（详细）

**文件**：`ai/memory/manager.py`

**接口**：

| 方法 | 层 | 说明 |
|------|-----|------|
| `start_session(title)` | - | 创建 session |
| `append_working(session_id, role, content, tool_calls=None)` | L1 | 追加消息 |
| `get_working_context(session_id, limit=50)` | L1 | 读上下文 |
| `save_episode(session_id, summary, trajectory, success)` | L2 | 归档 |
| `find_similar_episodes(query, top_k=3)` | L2 | 关键词匹配 |
| `upsert_selector(url, role, selector, by, success=True)` | L3 | 更新 registry |
| `rag_search(query, top_k=5)` | L3 | 检索 chunks + selectors |
| `mark_selector_stale(url_pattern, selector)` | L3 | CI 失败降权 |
| `record_skill_candidate(name, desc, success=True)` | L4 | 记录晋升候选 |
| `get_skill_candidates(min_success=3)` | L4 | 列出候选 |

**验收**：`tests/ai/test_memory.py` 全部通过。

## T06 — LLM Client（详细）

**文件**：`ai/llm_client.py`

- 读 `llm` 配置；`api_key` 从 `api_key_env` 环境变量
- `mock=True` 时返回预设响应（测试/agent 无网络）
- `chat(messages, tools=None)` → `{content, tool_calls, finish_reason}`
- 支持 OpenAI `chat.completions.create` 标准

**Mock 行为**：若 messages 末条含「生成用例」，返回 `validate_test_case` tool_call。

## T07-T09 — Tools（详细）

**schemas.py**：导出 `ALL_TOOLS` OpenAI function 格式列表。

**framework_tools.py**（无 browser 依赖，可单测）：

- `validate_test_case(case_dict)` → `{valid, errors}`
- `load_test_cases(path)` → list
- `get_config()` → config subset
- `save_test_case_staging(case_dict)` → 写 `data/ai/staging/{id}.json`
- `suggest_selector(dom_elements, intent)` → 从候选列表选 selector

**browser_tools.py**（需 AgentContext.engine）：

- 封装 `Engine` 方法；`get_page_info` 返回 `{title, url, elements:[{tag,id,name,text,selector}]}`
